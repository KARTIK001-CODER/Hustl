## 🔐 AUTHENTICATION FLOW

```
1. User visits /mentor/dashboard
2. Check localStorage for 'auth_token' and 'user'
3. If missing → Redirect to /login
4. Parse user data
5. If role !== 'MENTOR' → Redirect to /login
6. Fetch page data with Bearer token
7. Display page content
```
