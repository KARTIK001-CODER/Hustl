## 🎨 Color Reference

### Status Badges
```
APPLIED     → Blue    (bg-blue-100 text-blue-700)
SCREENING   → Purple  (bg-purple-100 text-purple-700)
INTERVIEW   → Yellow  (bg-yellow-100 text-yellow-700)
TECHNICAL   → Orange  (bg-orange-100 text-orange-700)
OFFER       → Green   (bg-green-100 text-green-700)
ACCEPTED    → Emerald (bg-emerald-100 text-emerald-700)
REJECTED    → Red     (bg-red-100 text-red-700)
WITHDRAWN   → Gray    (bg-gray-100 text-gray-700)
```

### Gradients
```
Primary Button: from-blue-600 to-indigo-600
Background:     from-slate-50 via-blue-50/30 to-indigo-50/40
Logo:           from-blue-600 to-indigo-600
Avatar:         from-blue-500 to-indigo-600
```

## 📱 Responsive Breakpoints

```
Mobile:  < 768px   → 1 column, stacked
Tablet:  768-1024  → 2 columns
Desktop: > 1024px  → 3-4 columns
```

## 🔗 Navigation Links

All pages include these links:
- **Dashboard** → `/dashboard`
- **Internships** → `/internships`
- **Applications** → `/applications`
- **Feedback** → `/feedback`
- **Profile** → `/profile`
- **Logout** → Clears localStorage, redirects to `/login`

## ✨ Hover Effects

All interactive elements have:
- `hover:shadow-xl` - Enhanced shadow
- `hover:scale-105` - Slight scale up (cards)
- `hover:-translate-y-1` - Lift effect (cards)
- `transition-all duration-300` - Smooth transitions
